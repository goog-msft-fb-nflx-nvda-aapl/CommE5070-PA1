## Improvement queue (from 4-way deep research on IMPROVEMENT_RESEARCH_PROMPT.md — see IMPROVEMENT_FINDINGS.md for full reconciliation)
- [x] **MuQ frozen-probe sweep**, both tasks (`OpenMuQ/MuQ-large-msd-iter`, 24kHz native, drop-in MERT replacement in the existing layer-sweep+classifier+PCA pipeline) — top recommendation, all 4 sources converged on this first. **Done 2026-09-18**: found+fixed 2 transformers-version-drift bugs (same class as MERT's, see src/muq_features.py docstring + WORKLOG.md). Full sweep + classifier/PCA ablation on both tasks. **A: layer1+SVM no-PCA, top1=0.5076/top3=0.8712** — beats MERT frozen-probe best (0.470) and even edges out fine-tuned MERT's top1 (0.500), as a cheaper frozen probe. **B: layer2+logreg no-PCA, top1=0.500/top3=0.853** — beats MERT's best-for-B (0.471/0.755) by +2.9pt top1/+9.8pt top3, on the exact task every other technique this project failed to improve. New standalone-model best for B. See WORKLOG.md 2026-09-18 section for full tables.
- [x] **AF3-probability stacking / late fusion on Task 2** — combine Audio Flamingo 3's teacher-forced label probabilities (already computed) with the MERT probe's probabilities via `ensemble.py`-style weighted sweep or a small stacker classifier. Cheapest way to test whether AF3's Task 2 edge (58.8% vs our 47.1%) transfers into our own pipeline. **Done 2026-09-18** (`src/af3_stack.py`): weighted-sum sweep over both AF3 prompts x every available frozen/fine-tuned backbone (MERT, MuQ, fine-tuned MERT), both datasets, not just Task 2. **B: MuQ+AF3(cot_then_answer, w=0.4) → top1=0.6569/top3=0.8824, new overall best, beats AF3 alone (0.588) and MuQ alone (0.500).** **A: MuQ+AF3(direct, w=0.5) → top1=0.5530/top3=0.8485, also a new overall best**, beats the 3-way ensemble (0.5227). Caveat: weight chosen by sweeping the validation set itself — flagged for bootstrap-CI confirmation, see WORKLOG.md 2026-09-18 section. Updated "CURRENT overall-best configs" table in WORKLOG.md.
- [x] **LoRA fine-tune of MERT** (rank 4-8, top 6-8 layers only) + SpecAugment/mixup (no augmentation was used in the full-fine-tune runs) — direct test against the PETL paper's finding (arXiv:2411.19371) that PEFT beats full fine-tune on MERT at small data scale, which already matches our own Task 2 result. **Done 2026-09-18** (`src/finetune_lora.py`, Task B, 3 runs): rank8/top-8-layers/0.17%-trainable LoRA, best case (no augmentation, 40 epochs) only reached top1=0.382 — well below frozen MERT (0.471), frozen MuQ (0.500), and the MuQ+AF3 fusion (0.657); confirmed plateaued (not under-converged) by running 2.7x longer for only +2pt. **Genuine negative result, contradicts the PETL paper's GTZAN finding** — reported as a task/dataset-regime difference (Task B is our smallest, most editorial/non-acoustic label), not a contradiction. Task A not run given this result + A's configs already being statistically indistinguishable (see significance testing above); deprioritized, not presumed to fail. Full curves in WORKLOG.md.
- [x] **Confusion-matrix / pairwise-AUC diagnostic on Task 2** — analysis only, no training: check whether Task 2 difficulty concentrates in specific market pairs (e.g. US/UK/Germany/Italy sharing 1980s Anglo/Euro-pop production) vs. spread evenly. **Done 2026-09-18** (`src/confusion_diagnostic.py`, both tasks): **B confirms the market-clustering hypothesis** — US/UK confusion (AUC 0.66-0.76) and Germany (worst class, F1~0.40) are the weak points, while Brazil is nearly perfectly separated (AUC 0.97-1.0), matching the "editorial category, not acoustic" explanation. **A shows clean ordinal/adjacent-decade confusion** (2000s vs 2010s AUC 0.69, 1960s vs 2010s AUC 0.96+) — a genuinely different, distance-structured error pattern vs. B's cluster-structured one. Full tables in WORKLOG.md.
- [x] Statistical significance (bootstrap CI / McNemar) for Task 2 comparisons — n=102 val set means several "X beats Y" claims at 2-3 points may not be distinguishable from noise; apply retroactively before further "doesn't help Task 2" conclusions. **Done 2026-09-18** (`src/significance.py`, 10000-resample paired bootstrap + exact McNemar, both tasks): **B — fusion (0.657) significantly beats MuQ-alone and MERT-alone (p<0.01) but is NOT significantly different from AF3-alone (0.588, p=0.21)**, so the fusion mechanism is confirmed real, the specific edge over AF3 is not. **A — none of the top 4 configs (0.492-0.553) are statistically distinguishable from each other at n=132** — the "new best" 0.553 claim from af3_stack.py is a point estimate only, not a confirmed win; report the 0.523 3-way-ensemble as the safer/confirmed number for A if a single figure is needed. Full tables + honest framing guidance in WORKLOG.md's "Statistical significance" section.
